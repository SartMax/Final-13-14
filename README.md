# Планировщик задач (Task Scheduler)

Веб-сервер для управления списком задач с поддержкой повторяющихся событий.

## Описание проекта

Проект представляет собой REST API сервер для планировщика задач с веб-интерфейсом. 
Позволяет создавать, редактировать, удалять задачи, а также отмечать их выполнение. 
Поддерживает различные правила повторения задач (ежедневно, еженедельно, ежемесячно, ежегодно).

### Основные возможности:
- Создание задач с указанием даты, заголовка, комментария и правила повторения
- Просмотр списка ближайших задач
- Редактирование существующих задач
- Отметка о выполнении задач (с автоматическим пересчетом даты для повторяющихся задач)
- Удаление задач
- Поиск задач по заголовку, комментарию или дате
